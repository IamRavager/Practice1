## CSS variables and mobile breakpoint value:
* Mobile breakpoint: 800px (`@media (max-width: 800px)`)
* CSS Variables (Design Tokens):
  * `--bg` — background color
  * `--panel` — panel/card background color
  * `--text` — primary text color
  * `--muted` — secondary/muted text color
  * `--accent` — accent color (used for buttons, badges)
  * `--gap` — standard spacing (1rem)
  * `--radius` — border radius for rounded corners (12px)
  * `--sidebar` — fixed width of the desktop sidebar (240px)
